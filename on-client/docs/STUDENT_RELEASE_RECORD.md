## 7. 데이터 보존 계획

`docs/STUDENT_RUNBOOK.md` 11장에 백업·복원·제한을 표로 적었습니다. 요약은 다음과 같습니다.

- 학생 코드와 문서는 Git에 커밋하고 `git push`로 GitHub에 올립니다. 복원은 새 폴더에 `git clone` 후 `git checkout <커밋>`입니다. 이 복원은 4장에서 실행 확인했습니다.
- 예제 모드 화면 값은 저장하지 않습니다.
- 계정 연결 설정과 자격 보관소는 프로젝트 밖의 Windows 사용자 폴더에 있으며 다른 PC로 옮기지 않고 새 PC에서 다시 연결합니다. 이전과 복원은 시험하지 않았습니다(미확인).
- `.env`와 키·토큰은 커밋하지 않고 어디에도 적지 않습니다.

## 9. 지원 범위와 버전 선언

- 이 프로젝트는 **검증 중인 버전**입니다. 버전은 앱 0.2.14이며, 지원 환경은 Windows와 PowerShell입니다. macOS와 Linux는 지원하지 않는 환경으로 봅니다.
